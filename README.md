# School 21 Desktop

Неофициальный клиент платформы [platform.21-school.ru](https://platform.21-school.ru/) для Windows, macOS и Linux.

> Приложение не связано со Школой 21 официально: показывает сайт платформы и данные её API, только читая их.
> Логин и пароль (если включить автовход) хранятся в защищённом хранилище системы и отправляются только на
> `auth.21-school.ru`.

## Экосистема School 21

Неофициальные клиенты платформы для всех устройств — с автовходом, закладками, «Где сидит пир» и уведомлениями.

| Android | [school_21_mobile](https://github.com/Dlzxn/school_21_mobile) | [последний релиз](https://github.com/Dlzxn/school_21_mobile/releases/latest) |

| iPhone | [school_21_ios](https://github.com/Dlzxn/school_21_ios) | в разработке |

## Возможности

- **Платформа в отдельном окне** — в цвет сайта, внешние ссылки открываются в браузере.
- **Автовход** — платформа завершает сессию пару раз в день; приложение само вводит логин и пароль.
- **Живёт в трее** — крестик прячет окно, уведомления продолжают приходить. Можно запускать вместе с системой.
- **Уведомления**: напоминания за 15 минут о событиях и проверках, на которые вы записаны; «колокольчик»
  платформы; новые события кампуса.
- **Где сидит пир** — кластер, ряд и место по логину.
- **Закладки** — «⋯» → «Закрепить эту страницу»: нужный раздел или проект в один клик. Кнопка ⌂ у закладки
  делает её стартовой: приложение будет открываться сразу на ней, а не на главной.

Всё дополнительное — кнопкой **⋯** в правом нижнем углу окна: «Где сидит пир», «Настройки»,
«Открыть в браузере». То же есть в меню значка в трее (там же «Выход»).

## Установка

Скачайте файл для своей системы из [последнего релиза](https://github.com/Dlzxn/school_21_desktop/releases/latest):

| Система | Файл |
|---|---|
| Windows 10/11 | `School 21_X.Y.Z_x64-setup.exe` (или `.msi`) |
| macOS Apple Silicon (M1–M4) | `School 21_X.Y.Z_aarch64.dmg` |
| macOS Intel | `School 21_X.Y.Z_x64.dmg` |
| Linux | `.AppImage`, `.deb` или `.rpm` |

Сборки не подписаны сертификатом разработчика, поэтому система предупредит:
- **Windows**: «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- **macOS**: если пишет, что приложение «повреждено» — выполните в Терминале
  `xattr -cr "/Applications/School 21.app"` и откройте снова.

## Разработка

Нужны [Rust](https://rustup.rs), Node.js 20+ и [зависимости Tauri](https://v2.tauri.app/start/prerequisites/)
для вашей системы (на Windows — Visual Studio Build Tools с C++ и WebView2).

```bash
npm install
npm run tauri dev      # запуск с горячей перезагрузкой
npm run tauri build    # установщики в src-tauri/target/release/bundle/
```

Релиз: поставьте тег `vX.Y.Z` (версия в `package.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`),
GitHub Actions соберёт установщики для всех систем в черновик релиза.

### Устройство

```
src-tauri/src/
├── config.rs     — адреса, клиенты Keycloak, дословные GraphQL-запросы сайта
├── api.rs        — токены Keycloak, официальный Open API, внутренний GraphQL (только чтение)
├── autologin.rs  — заполнение формы входа Keycloak, защита от петли
├── sync.rs       — фоновая синхронизация, уведомления, напоминания
├── windows.rs    — главное окно с сайтом, кнопка «⋯», локальные окна, трей
├── commands.rs   — команды для локальных окон
└── store.rs      — keyring и JSON-настройки
src/              — локальные окна: настройки и «Где сидит пир» (TypeScript без фреймворка)
```

Окно с сайтом платформы **не имеет доступа к IPC приложения** (capabilities выданы только локальным окнам).
